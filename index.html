Restore a backup
Restore is run on Ubuntu with an explicit confirmation and pre-restore safety backup.

1. Download or locate the backup file on the Ubuntu server.

2. Run sudo /opt/northstar-it/restore.sh /opt/northstar-it/backups/<backup-file>.

3. Review the file checksum and type RESTORE. The current database is backed up before replacement.

For off-server protection, copy completed backup files to a separate encrypted NAS or backup system.
